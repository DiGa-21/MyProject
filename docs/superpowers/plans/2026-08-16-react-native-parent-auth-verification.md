## Ручная проверка

Виртуальное устройство `Pixel_6_API_34` успешно запущено с холодной загрузкой. React Native APK установлен и открыт через Metro. Проверены стартовый экран, переход в кабинет родителя и отсутствие ошибки локальной конфигурации Supabase.

Реальным запросом к Supabase проверены два безопасных сценария без использования личных данных:

- неверные тестовые данные входа показывают русское сообщение `Неверная почта или пароль`;
- форма восстановления показывает нейтральное сообщение `Если аккаунт с такой почтой существует, мы отправили письмо`.

Регистрация, восстановление сохранённой сессии, выход и получение настоящего recovery-link покрыты автоматическими тестами. Повторная ручная проверка успешного входа не выполнялась автоматически, чтобы не вводить пароль пользователя через терминал и не создавать лишний аккаунт в рабочем Supabase-проекте.

Физический Android-телефон во время повторной проверки не был подключён к ADB. Проверка выполнена на эмуляторе; ограничение явно зафиксировано и не влияет на сохранность резервной Kotlin-версии.
