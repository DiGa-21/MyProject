# Эпик 08. Помощник, факт и английское слово

## Цель

Добавить тёплую мотивацию без свободного чата и навязчивых уведомлений.

## Задачи для AI-программиста

1. Создать библиотеку безопасных коротких фраз помощника.
2. Выбирать напоминание только для дела, у которого наступило подходящее окно.
3. Показывать один факт дня и одно лёгкое английское слово с переводом.
4. В конце дня спросить факт и слово; принимать короткий ответ ребёнка.
5. При правильном ответе начислять опыт персонажу.
6. Добавить настройки частоты и полного отключения помощника.

## Готово, если

- помощник не предлагает «почистить зубы» в неподходящее время;
- нет свободной генерации сообщений без фильтра и родительского контроля;
- контент можно заменить без выпуска новой версии приложения.
