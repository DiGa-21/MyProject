# Эпик 02. Семья и профили детей

## Цель

Создать родительский профиль и несколько детских профилей с понятными именами и персонажами.

## Задачи для AI-программиста

1. Ввести модели `Family`, `ParentProfile`, `ChildProfile`, `AvatarType`.
2. Реализовать создание, изменение и архивирование профиля ребёнка.
3. Разрешить имя/псевдоним ребёнка и отдельное имя, которым профиль помечает родитель.
4. Добавить выбор акула, собака, кошка, лисёнок и сохранение выбора.
5. Добавить необязательный PIN родителя; не хранить PIN в открытом виде.
6. Сделать переключатель текущего ребёнка только в родительском режиме.

## Готово, если

- один родитель видит минимум двух детей и может переключаться между ними;
- детский режим не позволяет открыть настройки другого ребёнка;
- удаление заменено архивированием, чтобы не терять историю.
