# Эпик 09. Родительская панель

## Цель

Собрать все родительские действия в одном месте и дать обзор по каждому ребёнку.

## Задачи для AI-программиста

1. Сделать карточки детей с сегодняшним прогрессом.
2. Добавить создание, редактирование и архивирование дел.
3. Добавить очередь неподтверждённых результатов.
4. Добавить управление сложностью, звёздами, сюрпризом и повторной игрой.
5. Добавить историю изменений и отмену решения.
6. Установить родительскую защиту при каждом чувствительном действии.

## Готово, если

- родитель видит всех детей, не смешивая их дела и награды;
- изменение одного ребёнка не меняет данные другого;
- аннулирование подтверждения сразу отражается в детском режиме.
