# Эпик 04. Выполнение и подтверждение

## Цель

Сделать прозрачный процесс: ребёнок сообщает о выполнении, родитель подтверждает или отмечает уважительную причину.

## Задачи для AI-программиста

1. Ввести статусы `planned`, `submitted`, `approved`, `rejected`, `excused`.
2. Реализовать подтверждение фото, коротким видео или голосовым сообщением.
3. Дать родителю кнопку «Подтвердить лично» без вложения.
4. Дать родителю кнопку «Уважительная причина» с необязательным комментарием.
5. Показать ребёнку понятную причину отказа без стыда и штрафов.
6. Ограничить доступ к вложениям профилем семьи.

## Готово, если

- повторная отправка результата не создаёт дубликат дела;
- `excused` засчитывается для дневного обязательного прогресса;
- родительское решение записывается с датой и автором.
