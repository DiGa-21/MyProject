# Эпик 01. Основа приложения и навигация

## Цель

Сделать устойчивый каркас Android-приложения с выбором режима и навигацией между экранами.

## Задачи для AI-программиста

1. Описать маршруты `mode_selection`, `child_home`, `parent_home` и `settings`.
2. Перенести временную навигацию из состояния экрана в отдельный слой навигации.
3. Добавить понятные состояния загрузки, ошибки и пустого списка.
4. Сохранить Compose-тему, крупные зоны нажатия и русский интерфейс.
5. Написать UI-тесты: выбор каждого режима, возврат назад, отсутствие падения при повороте.

## Готово, если

- обе карточки режима нажимаются на физическом телефоне;
- системная кнопка «Назад» работает предсказуемо;
- экран не теряет выбранный профиль при пересоздании Activity;
- `assembleDevDebug` и UI-тесты проходят.
