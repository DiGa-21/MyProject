# Эпик 06. Мини-игры

## Цель

Дать ребёнку короткую награду после обязательных дел, не превращая приложение в бесконечную игру.

## Задачи для AI-программиста

1. Сделать экран выбора доступной мини-игры.
2. Реализовать пазл как первую игру: фрагменты, прогресс, завершение.
3. Добавить вторую простую игру; вид и правила согласовать до разработки.
4. Разрешать одну повторную игру по правилу родителя.
5. Отзывать доступ при отмене подтверждения дела.
6. Сохранять результат игры идемпотентно.

## Готово, если

- игра открывается сразу после выполнения обязательных дел;
- завершённый пазл выдаёт фрагмент/награду один раз;
- ребёнок не может получить награду повторным быстрым нажатием.
