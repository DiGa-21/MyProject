# Эпик 11. Уведомления и безопасность

## Цель

Напоминать вовремя и защищать детские данные.

## Задачи для AI-программиста

1. Планировать локальные уведомления по временным окнам дел.
2. Не отправлять напоминания после выполнения/уважительной причины.
3. Добавить тихие часы и настройку частоты.
4. Ограничить родительские действия PIN/биометрией устройства, если доступно.
5. Проверить права на фото, видео, микрофон и уведомления.
6. Добавить удаление экспорта/вложений по запросу родителя.

## Готово, если

- уведомление не раскрывает лишние сведения на заблокированном экране;
- приложение работает при отказе от камеры/микрофона;
- родитель может отключить уведомления полностью.
