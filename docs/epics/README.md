## Правило для AI-программиста

Перед изменением кода AI-программист читает `README.md`, `docs/technical-specification.md`, текущую архитектуру и выбранный эпик. В ответе он сообщает изменённые файлы, команды проверки и оставшиеся ограничения. Нельзя подключать Firebase, реальные ключи или платные сервисы без отдельного подтверждения.
