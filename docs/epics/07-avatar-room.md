# Эпик 07. Персонаж, комната и предметы

## Цель

Показать долгосрочный прогресс ребёнка через персонажа и персонализацию.

## Задачи для AI-программиста

1. Создать экран персонажа с уровнями и опытом.
2. Добавить комнату с размещением предметов.
3. Добавить каталог одежды, аксессуаров и мебели.
4. Покупать предметы за звёзды/фрагменты с проверкой баланса.
5. За правильный факт и английское слово давать опыт для прокачки.

## Готово, если

- предмет нельзя купить при недостатке валюты;
- изменения комнаты сохраняются после перезапуска;
- ребёнок может отказаться от косметической покупки без потери звёзд.
