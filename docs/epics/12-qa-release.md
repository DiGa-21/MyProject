# Эпик 12. Качество и выпуск

## Цель

Подготовить стабильную семейную сборку и безопасный процесс дальнейшей разработки.

## Задачи для AI-программиста

1. Добавить unit-тесты правил дел, звёзд, доступности игры и отзыва награды.
2. Добавить Compose UI-тесты основных пользовательских сценариев.
3. Проверить размеры шрифтов, контраст, TalkBack и зоны нажатия.
4. Проверить Android-устройства от API 28 до актуального API.
5. Настроить GitHub Actions: сборка, lint и тесты без секретов.
6. Подготовить `devDebug` для тестирования и подписанный `prodRelease` только после отдельного решения.

## Готово, если

- CI не принимает commit с падающими тестами или lint;
- APK собирается воспроизводимо из чистого checkout;
- в репозитории нет `local.properties`, Firebase-ключей, keystore и личных фото/видео.
