# Эпик 10. Хранилище и синхронизация

## Цель

Сделать приложение полезным без интернета и подготовить семейную синхронизацию.

## Задачи для AI-программиста

1. Перенести модели в Room/локальное хранилище.
2. Определить идентификаторы, версии схемы и миграции.
3. Реализовать очередь локальных изменений.
4. Подключить Firebase только после создания отдельного проекта и правил доступа.
5. Синхронизировать профили, дела, решения, звёзды и предметы.
6. Разрешить повторную отправку после временной ошибки сети.

## Готово, если

- приложение запускается и показывает сегодняшние дела без сети;
- повторная синхронизация не создаёт дубликаты;
- данные одного семейного аккаунта недоступны другому.
