# Что нужно проверить перед разработкой

Этот файл предназначен для проверки владельцем приложения. Здесь нет программного кода и технических инструкций.

## 1. Регистрация и вход родителя

- После нажатия **«Режим родителя»** приложение проверяет, входил ли родитель раньше.
- Если родитель ещё не вошёл, открывается одна страница с двумя вкладками: **«Вход»** и **«Регистрация»**.
- На странице используется утверждённый дизайн: тёплый светлый фон, портрет помощника родителя, бирюзовая рамка позади персонажа и выступающие над рамкой уши.
- Во вкладке **«Вход»** находятся:
  - электронная почта;
  - пароль;
  - кнопка показа или скрытия пароля;
  - кнопка **«Войти»**;
  - ссылка **«Забыли пароль?»**.
- Во вкладке **«Регистрация»** находятся:
  - имя родителя;
  - электронная почта;
  - пароль;
  - повтор пароля;
  - кнопка **«Создать аккаунт»**.
- Минимальная длина пароля — **6 символов**.
- Если данные заполнены неправильно, понятная ошибка показывается рядом с нужным полем.
- Во время загрузки кнопку нельзя нажать повторно, но её размер не меняется.

## 2. Что происходит после регистрации

- Родитель проходит регистрацию только один раз.
- Сессия сохраняется на устройстве.
- При следующем запуске сначала остаётся общий выбор режима.
- После нажатия **«Режим родителя»** кабинет открывается без повторного ввода почты и пароля.
- Снова вводить пароль потребуется после явного выхода из аккаунта, удаления данных приложения либо прекращения действия сессии.
- В профиле родителя будет кнопка **«Выйти из аккаунта»**.
- Если в Supabase включено подтверждение электронной почты, после регистрации приложение попросит открыть письмо. Если подтверждение отключено, кабинет откроется сразу.

## 3. Восстановление пароля

- После нажатия **«Забыли пароль?»** появляется небольшое окно для ввода электронной почты.
- После отправки показывается нейтральный текст: **«Если аккаунт с такой почтой существует, мы отправили письмо»**.
- По ссылке из письма снова открывается приложение.
- Родитель попадает на страницу **«Новый пароль»**.
- Новый пароль нужно ввести дважды; минимальная длина — 6 символов.
- После успешного изменения пароля открывается кабинет родителя.

## 4. Создание профиля ребёнка родителем

- Сначала родитель создаёт профиль ребёнка в своём кабинете.
- Родитель задаёт ребёнку начальное имя или псевдоним.
- Родитель может добавить отдельную пометку, чтобы различать детей, например **«Саша, школа»**.
- Эта пометка видна только родителю. Ребёнок её не видит и не может изменить.
- Ребёнок позднее может изменить своё видимое имя в своём профиле.
- Дракона родитель не выбирает.

## 5. Первое подключение ребёнка

- Родитель нажимает **«Подключить устройство ребёнка»**.
- Приложение показывает одноразовый код из **6 цифр**.
- Код действует **15 минут**.
- Код можно использовать только **один раз**.
- Если родитель создаёт новый код, предыдущий код сразу перестаёт действовать.
- На своём устройстве ребёнок выбирает **«Режим ребёнка»** и вводит этот код.
- Почта и пароль родителя ребёнку не нужны.
- После успешного ввода кода ребёнок сам выбирает дракона:
  - Том;
  - Лили.
- Перед продолжением ребёнок может оставить имя родителя или изменить своё видимое имя.

## 6. Последующие запуски детского режима

- После первого успешного подключения устройство запоминает профиль ребёнка.
- При следующих запусках повторно вводить код не нужно.
- После выбора **«Режим ребёнка»** открывается его профиль и комната.
- На одном семейном устройстве сессии родителя и ребёнка хранятся отдельно и не должны отключать друг друга.
- Родитель может отключить детское устройство в своём кабинете.
- После отключения на детском устройстве снова появится страница ввода одноразового кода.

## 7. Защита детского подключения

- Сам код не хранится на сервере в открытом виде.
- Код не предоставляет ребёнку доступ к кабинету родителя или профилям других детей.
- После пяти последовательных неверных попыток ввод блокируется на **5 минут**.
- На экране показывается, сколько осталось ждать до следующей попытки.
- Пароли, коды подключения и ключи сессий не должны попадать в журналы приложения.

## 8. Что останется без изменений

- Общий стартовый экран выбора режима остаётся.
- Существующий дизайн комнаты ребёнка остаётся.
- Существующий дизайн кабинета родителя остаётся, кроме добавления авторизации, выхода и управления подключением ребёнка.
- Ребёнок по-прежнему сможет отмечать и отменять выполнение своих дел.
- Родитель по-прежнему сможет управлять делами ребёнка и своими делами.

## Что вам не нужно проверять

В технических планах ниже находятся английские названия файлов, классов, функций, тестов и команды для программиста. Их переводить и проверять не нужно. Для согласования поведения приложения достаточно проверить пункты этого файла.
